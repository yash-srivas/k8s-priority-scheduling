What these controls run

Normal placement uses scripts/run-experiment-1.ps1 and creates experiments/experiment-1.yaml. The order stage runs scripts/run-scheduling-order.ps1 with -Stage Prepare then -Stage Release. Both contestants use configs/order-priority-classes.yaml and have the same CPU and memory requests.

Experiment 3 runs scripts/run-experiment-2.ps1 with the Prepare, Equal, Preempt, or Compare stage chosen above. Each stage stops for inspection. Submitted JSON and admitted Pod YAML are saved for the run.
