## Evidence limits

The order test compares placement for one controlled opportunity on one worker. The default scheduler has separate eligibility and backoff behavior. Other workload changes, expired events, or a different binding can make a repeat inconclusive. Event creation timestamps may tie. The strongest proof here is that only the high UID bound while the comparable low UID stayed unbound, after both were observed Pending. Hardware readings from kind are per-container node accounting on one shared host. Metrics Server is optional.
